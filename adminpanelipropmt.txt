# CADDE54 VIBE — ADMIN PANEL GELİŞTİRME PROMPTU

Sen deneyimli bir **Senior React + TypeScript frontend geliştiricisisin.**

Mevcut **Cadde54 Vibe** isimli sosyal medya/PWA projesine profesyonel bir **Admin Panel** geliştir.

## 1. TEKNOLOJİ

Mevcut projedeki teknolojileri koru.

Tercih:

* React
* TypeScript
* Vite
* Tailwind CSS
* React Router
* Lucide React
* Zustand
* localStorage
* Recharts veya benzeri grafik kütüphanesi

Backend şu anda hazır değil.

Bu nedenle bütün admin işlemleri şimdilik **mock data + localStorage** ile gerçekten çalışmalı.

Ancak kod mimarisini ileride:

```text
React Admin Panel
        ↓
REST API
        ↓
Node.js / Express
        ↓
PostgreSQL
```

şeklinde kolayca backend'e bağlanabilecek şekilde oluştur.
